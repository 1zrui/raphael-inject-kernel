# Raphael (K20 Pro) Kernel with Frame Injection

Applies the QCACLD-3.0 frame injection patch from Loukious to LineageOS sm8150 kernel (lineage-23.2).

Enables 802.11 management frame injection on monitor mode interfaces (deauth, probe requests).

Source patch: https://github.com/Loukious/android_kernel_xiaomi_sm8150/commit/65c6a05ecd9b25ebf0742d39987c6a8a042227f1
